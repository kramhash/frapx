This documentation site and the [playground](/frapx/playground/) use
**Google Analytics 4** to see how they are used — which pages are read, where
visitors come from, and how often the playground's install code is copied —
so the project can tell what helps people get started.

## What is sent, and to whom

- **Recipient:** Google LLC (Google Analytics).
- **Sent:** the page you view (address without the `#…` part), the referring
  page, browser and device type, approximate location from your IP address,
  and a random identifier stored in a cookie (`_ga`). In the playground, also
  which of these you used: copying install code (and which tab), copying a
  share URL, picking a starter, opening a baked SDF volume (sample or file).
- **Never sent:** the shader you write, file names, slider values, or the
  playground's share link contents. Files you open stay in your browser.
- **Purpose:** understanding usage of the docs and playground. No advertising
  features are enabled.

## How to opt out

- Use a content blocker, or install Google's
  [opt-out browser add-on](https://tools.google.com/dlpage/gaoptout).
- Blocking analytics does not change how the site or the playground works.

See also [Google's privacy policy](https://policies.google.com/privacy).

## 日本語

このドキュメントサイトと[プレイグラウンド](/frapx/playground/)は、利用状況を把握するために
Google Analytics 4（送信先: Google LLC）を使っています。

- **送る情報:** 閲覧したページ（`#` 以降を除いたアドレス）、参照元、ブラウザと端末の種類、
  IP アドレスから推定したおおよその地域、Cookie（`_ga`）に保存するランダムな識別子。
  プレイグラウンドでは、導入コードのコピー（どのタブか）、共有 URL のコピー、
  スターターの選択、焼いた SDF の読み込み（サンプルかファイルか）を送ります。
- **送らない情報:** 書いたシェーダー、ファイル名、スライダーの値、共有リンクの中身。
  開いたファイルはブラウザの外に出ません。
- **目的:** ドキュメントとプレイグラウンドの利用状況の把握。広告の機能は使っていません。
- **止める方法:** コンテンツブロッカーを使うか、Google の
  [オプトアウト アドオン](https://tools.google.com/dlpage/gaoptout) を入れてください。
  止めてもサイトとプレイグラウンドの動作は変わりません。
